# 📅 Suu Calendar: A Dynamic Date Tracker

A clean, interactive and responsive calendar application built using **HTML, CSS and JavaScript** to accurately track and visualize dates.

## ✨ Current Features

* **Date Navigation:** Easily move between months and years using the clear navigation buttons (the `<` and `>`).
* **Accurate Month Display:** The calendar dynamically calculates and displays the correct number of days and starts the grid on the appropriate day of the week for the selected month.
* **Current Date Highlight:** The current day is visually marked with a distinct color (as seen in the screenshot, December 14th, 2025 is highlighted).
* **Responsive Layout:** The calendar grid and controls are designed to adjust gracefully to different screen sizes.
* **Clean and Intuitive UI:** The simple design prioritizes readability and ease of use.

## 🛠️ Technologies Used

* **HTML5:** Provides the foundational structure for the calendar.
* **CSS3:** Handles the aesthetic design, color scheme and the **responsive grid layout**.
* **JavaScript (ES6+):** Manages all date logic, including determining the current date, calculating days per month and handling the dynamic display.
